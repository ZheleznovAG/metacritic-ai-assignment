# Журнал допущений

## Назначение и статусы

Документ фиксирует результат `FOR-03`. Допущения нужны только там, где [`assignment.md`](../../assignment.md) допускает разные наблюдаемые варианты поведения.

Статусы:

- `Accepted provisionally` — принято исполнителем как простое обратимое правило до письменного уточнения;
- `Deferred to spike` — параметр или факт должен быть уточнён указанным исследованием до реализации;
- `Deferred to design` — внешние факты уже достаточны, но обратимый внутренний параметр выбирается в implementation baseline;
- `Bonus only` — действует только если дополнительная часть выбрана после ворот `G6`.

Ни одно допущение ниже не объявляется требованием автора задания.
